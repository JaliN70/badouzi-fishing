# 帥帥與爺爺 · 八斗子釣魚記

基隆 **八斗子** 漁港邊的輕量釣魚模擬，主角是 **帥帥** 與 **爺爺**。在手機瀏覽器體驗拋竿、等咬、刺魚與收線，魚種參考當地近海常見的魚。

## 玩法

1. **開始故事** → 跟爺爺一起來到堤岸  
2. **拋竿**：力道指標在綠色區域時按下  
3. **等浮標**：耐心等魚咬餌  
4. **刺魚**：浮標下沉時快速按「刺魚」  
5. **收線**：連按「收線」拉高進度，注意線張力不要過高  

累計尾數與重量會存在本機（`localStorage`）。

## 本地執行

```bash
npm install
npm run dev
```

預設：`http://127.0.0.1:43123`

## 建置

```bash

```
